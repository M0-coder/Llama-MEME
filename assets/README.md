# Canonical artwork

Two user-approved 1024x1024 RGBA PNG artworks are registered in `config/assets.manifest.json`:

- `llama-token-icon.png` — head/icon artwork for token/explorer/social use.
- `llama-character.png` — full-body character artwork for web and campaign use.

Their SHA-256 hashes are recorded before repository ingest. Binary ingestion is tracked separately so text-only foundation validation cannot silently substitute or mutate the artwork.
