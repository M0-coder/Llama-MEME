## Genesis allocation

| Allocation | Percent | Tokens |
| --- | ---: | ---: |
| Public launch / liquidity allocation | 85% | 850,000,000 |
| Community / ecosystem | 10% | 100,000,000 |
| Operating treasury | 5% | 50,000,000 |
| Team | 0% | 0 |
| Private sale | 0% | 0 |

`publicLaunch` is an allocation bucket, not a requirement to deposit all 850,000,000 LLAMA into one liquidity pool at launch. Pool design, initial SOL depth, venue, and launch mechanics require a separate reviewed execution plan.

## Authority target

After the canonical supply is minted and independently verified, the intended terminal state is:

- Mint authority: revoked.
- Freeze authority: revoked.

Revocation is irreversible and therefore must not occur until a dedicated deployment checklist has passed.
